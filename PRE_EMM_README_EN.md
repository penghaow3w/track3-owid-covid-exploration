# Pre-EMM exploration — 5 October 2026

Start with `owid_pre_emm_walkthrough_en.ipynb`: full executed code, explanations, audit tables and ten numbered figures. This is the latest work; the earlier `owid_analysis_en.ipynb` describes the initial exploration.

The companion `pre_emm_reproducible_2026-10-05.zip` preserves the notebook/scripts/results directory structure. Extract it into a project folder, install pandas, numpy, matplotlib, JupyterLab and ipykernel, then open the notebook under `notebooks/` and run all cells. The raw OWID snapshot is excluded. Place the original `compact_2026-10-04.csv` under `data/raw/`. A current download from https://catalog.ourworldindata.org/garden/covid/latest/compact/compact.csv may differ from the snapshot. Expected SHA256: `7481c676492771e8425b118eaa983e987dd7312989ddcf7c67de09e635c53abc`.

Completed:

- Daily-to-week validation with explicit missing, incomplete, negative, nonfinite and noninteger checks; no imputation.
- Country retention and descriptor coverage audit.
- K-digit probability model checks and fixed K1/K2 cohorts.
- Country-based descriptor quartiles shared across K1/K2.
- TV, base-2 Jensen–Shannon divergence and Hellinger comparison.
- Scores for 29 predefined single-condition rules per K.
- Minimum-support sensitivity and equal-country weighting comparison.
- Year-specific reporting coverage review.

Main findings: 45,170 positive complete weeks; the K1 core cohort contains 44,567 weeks across 226 locations, and K2 contains 37,590 weeks. Year 2026 ranks highest among the prepared rules under equal-week and equal-country TV scoring. Reporting coverage shrinks substantially in later years, so this is not evidence of fraud or a confirmed anomaly.

The archive contains small result tables, scripts and saved notebook output. Large raw data and derived country-week tables are excluded and regenerated by the notebook.

Remaining: common reporting-window/matched-country sensitivity; uncertainty respecting repeated country/time structure; confirmation of Lucas's repository/branch and model/quality interfaces; EMM integration and automatic search. Scores currently lack a sample-size penalty. The package is exploratory and contains no automatic EMM result.
